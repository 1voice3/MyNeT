MyNeT - your own private internet
=================================

HOW GOOGLE'S SEARCH BAR WORKS (simplified)
1. Alphanumeric processing: your query is lowercased, accents and punctuation are stripped, and it is split into tokens (letters and digits). "iPhone 15 Pro" becomes iphone | 15 | pro. Spelling correction, synonyms and stemming (run/running) are then applied.
2. Characterization (intent): Google classifies the query - navigational (go to a site), informational (learn), transactional (buy), local (near me) - and detects entities (people, places, products). Intent decides which result types are shown.
3. Matching: an inverted index maps every token to the pages that contain it. Pages that match the tokens (and meaning, via language models) form a candidate set.
4. Results priority (ranking): hundreds of signals score each candidate - text relevance (title, headings, body), links from other sites (PageRank), freshness, page quality and trust, speed, mobile friendliness, location, language, and your search context. Highest score is shown first, mixed with features such as maps, images, videos and snippets.

FULL-TEXT SEARCH INSIDE YOUR FILES
- When you add files or a whole folder, MyNeT reads the text inside them and stores it with the file: PDFs (every page), Word (.docx), PowerPoint (.pptx), Excel (.xlsx), and text-based files (txt, csv, json, md, html, xml, log and more).
- Search results show the matching passage with your words highlighted, and for PDFs the page number. Every word and number (part numbers, model numbers, fault codes) is searchable.
- Files added before this update are read automatically the next time you open MyNeT. THE LIST > gear > "Re-index all files" redoes everything.
- The first time in a session, MyNeT needs internet once to load the PDF/Office reader. After the text is stored, searching works offline.
- OCR (scanned pages and pictures): pages of a PDF with no real text layer are rendered and read by OCR, and every picture you add (photos, screenshots, scans) is read too. English is built in. OCR is slow on a phone (roughly several seconds per page); keep MyNeT open and the screen on while it works, and plug in for big scanned manuals. Turn it off or on under THE LIST > gear.
- OCR needs internet to load the reader and its English data the first time. Results are stored, so searching stays offline. Handwriting and low-quality photos may read poorly.
- Not searchable yet: pictures embedded inside Word/PowerPoint files, and old .doc/.xls/.ppt files. The list marks files with no readable text as "no searchable text".

HOW MyNeT DOES IT (inside index.html)
- Same steps on your own data: normalize -> tokenize -> every word must match -> score.
- Score = field weight (name 10, tag/kind 3, path or URL 4, note text 2) x match type (exact word 100%, word starts with 60%, contains 30%) + exact-name bonus + usage boost (times opened) + recency boost.
- File contents count too: whole words score higher than partial matches, more occurrences and an exact phrase score higher.
- The bar under each result shows relative relevance.

USING IT
- Launch: rotating 3D logo, bit code absorbed, morphs into a brain with neurons firing. Tap SKIP to enter early.
- SEARCH page: only the search bar. "+" adds, "LIST" opens the list.
- ADD: paste a link or note, or add files, pictures, or an entire Windows/Mac folder. Everything is stored in your browser (IndexedDB) and stays until you remove it.
- THE LIST sort options: latest added, oldest, latest searched/opened, A-Z, Z-A, 1-10, 10-1, alphanumeric, largest, smallest, type, and custom (move with up/down arrows). Filter by links, pictures, files, notes.
- Tap an item to open it. Links open in a new tab; notes, pictures, PDFs, video, audio and text files open inside MyNeT, with Share / Save to Files and Download buttons for any file. X removes an item.

TAGS
- Type tags (comma separated, e.g. hvac, trane, manual) in the ADD screen; they apply to everything you add in that batch.
- On THE LIST, tap # on any row to edit its tags. Use the tag filter to show one tag. Tags are searchable (type hvac or #hvac in the search bar).

THEMES
- THE LIST > gear: Cyber cyan, Violet neon, Matrix green, Ember, Daylight. Your choice is remembered.

BACKUP / RESTORE
- THE LIST > gear > Export full backup: one .json file with every item, file, picture, tag and your theme. Save it to Files / iCloud Drive.
- Restore from backup: pick that .json; items already in MyNeT are kept, only missing ones are added. Use it to move MyNeT to a new phone or browser.
- Back up regularly: browsers can clear site storage. The gear screen shows space used and your last backup date. MyNeT also asks the browser to keep its storage permanent.
- Very large libraries (several hundred MB) may be too big for one backup file on a phone; export more often, or back up from a computer.

NOTES
- Data lives on the device and browser you use. Use the same browser each time; clearing site data erases it.
- Folders are copied into MyNeT as files (browsers cannot keep live links to your folders).
- Hosting: upload index.html to GitHub Pages (or open it directly from Files on iPhone).
- Not included yet: bulk tag editing, sharing between devices without a backup file.
